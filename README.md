# Калькулятор (WPF) — практическая работа № 2

Выполнил: Давыдов Сергей Павлович, группа ИПо-33.

Программа «Калькулятор» на C# / WPF (.NET 8). Выполняет операции `+`, `-`, `*`, `/` и `^` (возведение в степень) с учётом приоритета и скобок: `2+3*4 = 14`, `(2+3)*4 = 20`, `-2^2 = -4`, `(-2)^2 = 4`. Работает с дробными и отрицательными числами, при делении на ноль выводит сообщение об ошибке.

## Структура решения

| Проект | Тип | Назначение |
|---|---|---|
| `DavydovCalculator.Core` | Библиотека классов | Логика калькулятора (классы `Calculator` и `ExpressionCalculator`) |
| `DavydovCalculator.Wpf` | Приложение WPF | Окно калькулятора |
| `DavydovCalculator.Tests` | Проект тестов MSTest | Модульные тесты для классов библиотеки |

## Запуск

1. Открыть `DavydovCalculator.sln` в Visual Studio 2022 или новее.
2. Нажать **F5**.
3. Тесты: меню **Тест → Запуск всех тестов**.

Сопроводительная записка — файл `Сопроводительная записка.pdf`.
